# Tic Tac Toe Game in JavaScript

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Player O and Player X turns
- Winner detection
- New Game button
- Reset Game button
- Prevents clicking on already selected boxes
- Simple and clean user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Player O starts the game.
2. Players take turns clicking on the boxes.
3. The first player to match three symbols in a row, column, or diagonal wins.
4. Click the Reset button to restart the game.
5. Click the New Game button after winning to start again.

## Winning Patterns

The game checks the following winning combinations:

- Horizontal
- Vertical
- Diagonal
